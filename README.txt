ӘМИЯН — iPhone-ға орнату (GitHub Pages, тегін)
================================================

1. github.com сайтына кіріп, тегін аккаунт ашыңыз (Sign up).
2. Жоғарғы оң жақтағы «+» → «New repository».
   Атауы: amiyan. «Public» деп қалдырыңыз → «Create repository».
3. «uploading an existing file» сілтемесін басыңыз.
   Осы архивтегі 6 файлды түгел апарып тастаңыз:
   index.html, manifest.webmanifest, sw.js, icon-180.png, icon-192.png, icon-512.png
   → «Commit changes».
4. Settings → Pages → Branch: «main», папка «/ (root)» → Save.
   1–2 минуттан кейін сілтеме шығады:  https://АТЫҢЫЗ.github.io/amiyan/
5. iPhone-да осы сілтемені SAFARI арқылы ашыңыз (Chrome емес).
6. Төмендегі «Бөлісу» (□↑) батырмасы → «Басты экранға қосу» (Add to Home Screen) → Қосу.

Дайын! Енді «Әмиян» иконкасы басты экранда тұрады, кәдімгі қосымшадай
толық экранда ашылады, интернетсіз де жұмыс істейді.

МАҢЫЗДЫ
- Деректер тек сіздің iPhone-да сақталады. Ешкім көрмейді, тіркелу жоқ.
- Айына бір рет: ⚙ Баптаулар → «Сақтық көшірме жасау» → iCloud Drive-қа сақтаңыз.
  Телефон ауыстырсаңыз немесе Safari деректерін тазаласаңыз — «Көшірмеден қалпына келтіру».
- Google Sheets-ке: ⚙ → «Google Sheets-ке экспорт (CSV)» → Sheets-те Файл → Импорттау.
- Кейін файлдарды жаңартсаңыз (GitHub-қа қайта жүктесеңіз), деректеріңіз өшпейді.
